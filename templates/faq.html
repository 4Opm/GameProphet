Frequently Asked Questions

What is GameProphet?

GameProphet is a football match prediction simulation powered by AI. Ten autonomous agents independently analyze upcoming matches and place bets based on their own unique strategy. Each agent has a virtual budget of $1,000 available for every single match - this resets per match, not per agent overall. The goal is to track which strategy performs best over time across real match data from top European leagues.

This is purely a simulation for entertainment and educational purposes. No real money is involved.

Which leagues are covered?

GameProphet currently tracks matches from four major European leagues:

  • Premier League — Top division of English football
  • Bundesliga — Top division of German football
  • Serie A — Top division of Italian football
  • La Liga — Top division of Spanish football

Match data is fetched automatically from the football-data.org API and updated every hour.

What data do the agents receive?

Before making a prediction, each agent receives a detailed context package containing:

  • Home and away team names, league and match date
  • Current bookmaker odds (HOME / DRAW / AWAY) averaged across multiple bookmakers
  • League standings for both teams — position, points, wins, draws, losses and goal difference
  • Average goals scored and conceded per match over recent games
  • Last 10 HOME games for the home team
  • Last 10 AWAY games for the home team
  • Last 10 HOME games for the away team
  • Last 10 AWAY games for the away team

This gives each agent a comprehensive picture of both teams before making a decision.

How do the agents work?

Each agent is powered by Llama 3.3 70B running on Groq — a large language model that analyzes the match context and returns a structured prediction. Each agent has a unique system prompt that defines its betting personality and strategy. The model returns three values: a prediction (HOME, DRAW or AWAY), a stake percentage and a one sentence reasoning explaining the decision.

If an agent sets the stake to 0%, it means the agent decided to skip the match due to insufficient confidence. This decision is final and the agent will not reconsider it.

Meet the agents

  • The Conservative — Only bets on clear favorites with odds below 1.7. Stakes between 5% and 60% depending on confidence. Skips matches where no clear favorite exists.
  • The Aggressive — Goes big on every match regardless of confidence. Stakes between 20% and 100%. Never skips a match.
  • The Analyst — Analyzes all available data before making a decision. Stakes between 5% and 55%. Skips if data is inconclusive.
  • The Lucky One — Ignores all data and bets purely on instinct. Stakes between 5% and 100% randomly. Reasoning is completely absurd.
  • The Follower — Always bets on the team higher in the league standings. Stakes between 5% and 65% based on the gap in positions.
  • The Quant — Looks for value bets where odds seem too high relative to team quality. Stakes between 5% and 60%. Skips if no value is found.
  • The Momentum Trader — Only bets on teams currently on a winning streak. Stakes between 10% and 60%. Skips if no team is on a streak.
  • The Draw Specialist — Looks for matches likely to end in a draw based on form and odds. Stakes between 5% and 55%. Skips if no draw signals found.
  • The Home Fortress — Only bets on home teams with strong home form. Stakes between 10% and 60% based on home winning streak. Skips if home form is weak.
  • The Contrarian — Always bets against what the bookmakers suggest. Stakes between 5% and 60%. Never skips.

How is profit and loss calculated?

Each agent has a fixed virtual budget of $1,000 per match — every match is treated independently and the full $1,000 is available regardless of previous results. The stake amount is a percentage of this $1,000 budget chosen by the agent for each match.

If the prediction is correct, profit is calculated using real bookmaker odds:

profit = stake × odds − stake

For example, if an agent stakes $200 on a team at odds of 2.50, the profit on a correct prediction is $300 ($200 × 2.50 − $200). If wrong, the agent loses the $200 stake. The dashboard balance starts at $0 and reflects the cumulative profit and loss across all settled bets.

Where do the odds come from?

Odds are sourced from The Odds API, which aggregates prices from major bookmakers including Pinnacle, Betfair, William Hill, Unibet, Betsson and others. GameProphet uses the average across all available bookmakers to get a fair market price. Odds are fetched once per day and only for matches taking place within the next 3 days. Agents will only place bets on matches that have odds available.

How often is data updated?

The scheduler runs every hour and performs the following tasks in order: fetches the latest match data for all three leagues, updates bookmaker odds once per day for matches within the next 3 days, places bets for upcoming matches that have odds available and have not yet been analyzed, and settles any completed matches by calculating profit and loss for each agent.
